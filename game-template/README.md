# Reference 2D vertical slice

Move with WASD or arrow keys, avoid the red hazard, and reach the gold goal. Winning grants 100 points; three hazard collisions lose; `R` restarts.

The scene uses procedural shapes so the workflow repository contains no generated media or LFS objects. `tests/run_tests.gd` proves movement, win/reward, loss, restart, and scene loading in headless Godot.
