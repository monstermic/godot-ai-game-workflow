# Generic adapter

Read the generated repository's root `AGENTS.md` and `.aigame/automation.json`. Run `aigame doctor --json`, then `aigame next --json`. Complete concept tasks, then drive `aigame assets next --json` through exhaustive planning, representative samples, deterministic generation, validation, and integration before implementation. In `human_gated` mode stop at approvals; in `ai_staging` mode accept CLI-generated agent approvals and continue. Target `staging`. Run `aigame staging merge` only to obtain the exact approval comment, then stop for the authenticated repository owner to post it. Never bypass dependency, provider, model-download, production, release, rollback, secret, paid-service, or destructive gates.
